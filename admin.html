Instrucciones para Docker Desktop

Para levantar el contenedor oficial de PostgreSQL en Docker Desktop, abre tu terminal y ejecuta: 

cd backend
docker compose up -d

El backend tiene tolerancia automática a fallos: sincroniza con PostgreSQL al iniciar y mantiene una copia activa en memoria.
